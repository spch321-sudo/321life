# 321生命操練

以「舊人有己生命檢視表」與「新人無己生命操練表」為核心的每日生命操練 App。
國度321空中團契出品。

## 功能

- **主視覺**：今日頁最上方顯示 321 主視覺方圖（`hero.jpg` 1080×1080、`hero-720.jpg` 720×720，依螢幕自動選用），也作為分享連結時的預覽圖。
- **生命健檢**：輸入一件事的「事件／感應（看到、聽到）／反應（意念、情緒）／回應（說了、做了）」，小智用 321 理念分析生命光景（舊人作王／新舊交戰／新人作王）、有己的根、觀點轉換、920 要結的果子、經文、更新建議、明天的無己行動與禱告；可一鍵帶入「更新記錄」，歷次健檢保存在本機。小智經由 `xiaozhi-proxy.spch321.workers.dev`，需在 `spch321-sudo.github.io` 網域上線後才會回應。
- **今日**：依星期帶出當天的檢視重點（一：看＋觀念；二：聽＋生命；三：想＋生活；四：講＋關係；五：行＋事工；六：同行分享；主日：感恩），一週打卡、今日聖靈果子、321 理念。
- **檢視舊人**：看聽想講行、觀念生命生活關係事工，共 50 題，0–3 分；完成後顯示光景與下一步、更新五步、認罪更新禱告。
- **操練新人**：與檢視表一一對應的 50 題操練，附經文、宣告與本週操練；完成後顯示成長階段、每日操練五步驟、晨間奉獻禱告。
- **成長**：每道門戶與領域的舊人／新人分數並排長條圖，以及歷次記錄。
- **日記**：更新記錄表、得勝見證記錄表（可勾選聖靈九果）。
- **備份**：匯出／匯入 JSON 備份檔，換手機時使用。
- **PWA**：可加到主畫面、離線使用、有新版時顯示「立即更新」。

所有記錄只存在使用者自己的瀏覽器（localStorage），不會上傳到任何伺服器。

## 發佈到 GitHub Pages

1. 在 GitHub 帳號 `spch321-sudo` 建立新的 repository，例如 `321life`（Public）。
2. 把這個資料夾裡的所有檔案（包含 `.nojekyll`）上傳到 repository 的根目錄。
3. 到 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
4. 約一分鐘後即可開啟：`https://spch321-sudo.github.io/321life/`

## 加到 iPhone 主畫面

用 Safari 開啟網址 → 分享 → 「加入主畫面」。圖示使用 `apple-touch-icon.png`（180×180，不透明背景）。
若之前加過舊版、圖示顯示成字母，請先從主畫面刪除，清除 Safari 該網站資料後再加一次。

## 更新版本

1. 修改 `index.html`。
2. 把 `sw.js` 第一行的 `VERSION` 加一（例如 `321life-v1.0.1`）。
3. 上傳覆蓋。使用者下次開啟時會看到「有新版本可以更新」。

## 更換主視覺

用同名檔案覆蓋 `hero.jpg`、`hero-720.jpg`（正方形），再把 `sw.js` 的 `VERSION` 加一。

## 技術規格

- 單一 `index.html`（約 52KB），JavaScript 為 ES5，相容 WPS／舊版 WebView。
- 字型：Noto Serif TC、Noto Sans TC（Google Fonts，離線時改用系統字型）。
- 深色模式自動跟隨系統設定。
