# 321生命操練

以「舊人有己生命檢視表」與「新人無己生命操練表」為核心的每日生命操練 App。國度321空中團契出品。
支援 **繁體中文／简体中文／English** 三語。

## 功能

- **三語切換**：頁首「繁｜简｜EN」一鍵切換；介面、五道門戶與五重領域 50 題、經文、禱告、小智回答語言、朗讀語音全部跟著換。简体由繁體自動轉換；英文經文採 World English Bible（WEB）。手機語言是简体或英文的新使用者，第一次開啟會自動選對；已經在用的舊使用者維持繁體。
- **字級與主題**：頁首「Aa」一鍵循環四段字級（標準／大／特大／超大）；設定裡可選淺色、深色或自動。
- **畫線**：點任何一句經文、題目、禱告或健檢結果就畫起來（預設金色）；再點一下開面板：8 種顏色、增減句數、整段、寫默想（顯示在段落下方）、問小智、朗讀這句、從這裡朗讀、複製、分享、刪除。「日記 → 畫線收藏」可看全部畫線，按「回到原處」跳回原文。畫線依語言分開保存。
- **朗讀**：右下 🔊 從畫面看得到的地方開始朗讀整頁，一句一句亮起並自動置中（自己捲動後 4 秒內不搶畫面）；跨段時自然帶入（「接下來是……」「讓我們一起禱告」）；經文出處唸成全名（馬太福音7章3節）；括號裡的出處、表情符號不唸；多音字依上下文校正。Azure 真人語音三選一、速度三段；連不上時自動改用手機內建語音。鎖屏、切到別的 App 都繼續唸，鎖屏畫面有暫停／上一段／下一段。
- **小智**：右下「智」開啟對話；以 321 理念陪你把真理用在看聽想講行、觀念生命生活關係事工；知道你目前在哪一頁、今天的重點與剛完成的分數。回答有標題、條列、引言、表格排版；每則可收藏、分享、複製、朗讀、刪除；長回答自動收合；回答太長被截斷時會自動接著寫完；回答下方有「說出口／家庭／職場／又跌倒／禱告／七天」追問鈕；可選回答對象（成人／青少年／兒童／慕道友）。
- **生命健檢**：輸入事件／感應／反應／回應，小智用 321 分析生命光景並給更新建議；可繼續追問（追問的回答也能朗讀、複製、分享、收藏，被截斷也會自動接續）。結果裡每一句都能畫線。
- **今日、檢視舊人、操練新人、成長、日記、備份**：與前版相同；備份檔現在也會一併帶走畫線與小智收藏。
- **自動更新**：發佈新版後，已安裝的 App 會自動換成新版；正在朗讀、小智回答中或打字中不會被打斷，只顯示更新條。設定頁有版本號、「檢查更新」「強制更新」。

所有記錄只存在使用者自己的瀏覽器（localStorage），不會上傳到任何伺服器。小智與真人語音需要網路，並在 `spch321-sudo.github.io` 網域上線後才會回應。

## 發佈／更新到 GitHub Pages

1. 把這個資料夾裡的 **所有檔案**（包含 `.nojekyll`）上傳覆蓋到 `spch321-sudo/321life` 的根目錄。
   這一版新增的檔案：`lang-zs.json`、`lang-en.json`、`version.json`，一定要一起上傳。
2. Settings → Pages：Deploy from a branch，`main`、`/ (root)`。
3. 約 1～10 分鐘後生效。使用者打開或切回 App 時會自動換成新版。

網址：`https://spch321-sudo.github.io/321life/`

## 加到 iPhone 主畫面

用 Safari 開啟網址 → 分享 → 「加入主畫面」。圖示 `apple-touch-icon-v2.png`（180×180）；Android 用 `icon-192-v2.png`、`icon-512-v2.png`、`icon-maskable-512-v2.png`。日後換圖示請改用新檔名（如 v3）。若主畫面圖示顯示成字母，請先刪除，清除 Safari 該網站資料後再加一次。

## 技術規格

- 單一 `index.html`（約 170KB，小於 183KB），JavaScript 為 ES5，相容 WPS／舊版 WebView；简体與英文字串放在 `lang-zs.json`、`lang-en.json`。
- 版本號同時寫在 `index.html`（APPVER）、`sw.js`、`version.json`，三處一致才會正確自動更新。
- 小智：`xiaozhi-proxy.spch321.workers.dev`；真人語音：`azure-tts.spch321.workers.dev`。
